# lgram — історія версій

## 1.3.0 (поточна)
- **Ідентифікація пристрою**: клієнт тепер представляється Telegram як
  реальний Android-пристрій (Samsung Galaxy S23, Android 14) замість
  дефолтної бібліотечної сигнатури Telethon — менший ризик, що сесію
  розцінять як підозрілу лише через очевидну "скриптову" ознаку.
- **Позначення прочитаним**: при відкритті чату lgram одразу повідомляє
  Telegram, що повідомлення прочитані (`send_read_acknowledge`) — непрочитане
  зникає і в самому Telegram на інших пристроях, і в lgram, одразу, не
  чекаючи наступного опитування.
- **Галочки ✓ / ✓✓**: власні повідомлення тепер показують, надіслано (✓) чи
  прочитано співрозмовником (✓✓) — через справжній `read_outbox_max_id`
  Telegram, так само, як у звичайному клієнті.
- **Миттєве відкриття списку чатів**: список кешується на диску й показується
  одразу при вході в застосунок, поки свіжі дані підвантажуються у фоні —
  більше не треба щоразу чекати мережевий запит, щоб побачити хоч щось.
- **Нормальні кнопки**: один спільний стиль (заокруглені, акцентного кольору,
  без КАПС-тексту) застосовано одразу до всіх кнопок застосунку.
- Замінено жахливу випадкову іконку гамбургер-меню на нормальну.

## 1.2.0
- **Ім'я акаунта більше не вводиться вручну** — одразу після успішного входу
  (коду чи QR) lgram підтягує справжні ім'я/прізвище/телефон із самого
  профілю Telegram. Це прибирає ризик, що хтось випадково впише
  невідповідне "ім'я" акаунта, яке Telegram може розцінити як підозріле.
- **Архів чатів**: вкладки "Усі чати" / "Архів" над списком — архівні чати
  більше не змішані з основними.
- **Аватарки**: фото чатів і власний аватар кожного акаунта тепер качаються
  ОДИН раз і кешуються в `cache/avatars/` — наступні відкриття застосунку
  не витрачають трафік повторно на ті самі фото.
- **Медіа більше не качається автоматично**: звичайний тап по фото/відео/
  кружечку/файлу спершу питає підтвердження, і лише тоді завантажує (якщо
  файл вже раз качали — відкриває миттєво з кешу без повторного запиту
  в мережу). Кнопка "Скачати в Download" у контекстному меню, як і раніше,
  кладе окрему копію в `downloads/`.
- **Надсилання файлів**: кнопка 📎 біля поля вводу — вибір будь-якого файлу
  з пристрою і надсилання в чат.
- **Автооновлення переписки**: поки чат відкритий, lgram тихо перевіряє нові
  повідомлення кожні ~4с (список чатів — кожні ~5с) — відповідь від
  боту/співрозмовника з'являється без потреби переходити в чат заново.
- **Контекстне меню оновлено**: замість простого списку — bottom sheet
  з іконками (Переслати/Редагувати/Скачати/Видалити).

### Відомо, що ще потребує роботи (наступні версії)
- Повноцінний "живий" push через Telegram-події замість періодичного опитування
  (поточний варіант простий і надійний, але не миттєвий — затримка до ~4-5с).
- Інлайн-перегляд фото/відео прямо в бульбашці повідомлення (зараз — через
  системний застосунок перегляду/плеєр).
- Папки (Telegram Folders) — поки лише розділення "Усі"/"Архів", без
  користувацьких папок.
- Подальша візуальна доробка під сучасний Telegram (анімації, свайп-жести).

## 1.1.1
- Додано вхід через QR-код як альтернативу коду в SMS/Telegram — кнопка
  "Увійти через QR-код" на тому ж екрані входу. QR-токен живе ~30с і
  автоматично оновлюється, поки код не відсканують (без необхідності
  починати вхід заново). Існуючий вхід за номером/кодом не змінювався.

## 1.1.0
- Реальний список чатів (замість заглушки) — підтягується з Telegram через Telethon.
- Екран переписки: текстові повідомлення, відправка тексту, визначення типу медіа
  (фото/відео/кружечок/голосові/аудіо/стікер/gif/документ) з іконкою та підписом.
- Тап по медіа-повідомленню → завантаження в кеш і відкриття системним переглядачем
  (перегляд фото/відтворення відео, аудіо, кружечків тощо — через застосунки,
  вже встановлені на пристрої).
- Довгий тап по повідомленню → контекстне меню: Переслати (з вибором чату),
  Редагувати (для власних текстових повідомлень), Видалити, Скачати
  (копія саме в `downloads/`, окремо від кешу перегляду).
- Екран налаштувань: редагування профілю (ім'я/прізвище/про себе), редагування
  дефолтних API ID/hash, і для кожного акаунта — експорт сесії (копія файлу
  в місце за вибором юзера, оригінал лишається) та видалення файлу сесії з
  підтвердженням (прибирає лише з lgram, без логауту в самому Telegram).

### Відомі спрощення цієї версії (плани на подальші версії)
- Перегляд фото/стікерів/відео відбувається через системні застосунки, а не
  вбудований плеєр/перегляд безпосередньо в бульбашці повідомлення.
- Стікери у форматі `.tgs` (анімовані) можуть не відкритись системним переглядачем,
  якщо на пристрої немає застосунку, що їх підтримує — звичайні `.webp`-стікери
  відкриються без проблем.
- Профіль (bio) підтягується лише для акаунта, позначеного активним за замовчуванням.
- API ID/hash у налаштуваннях поки лише один спільний дефолт для нових акаунтів,
  а не окремий на кожен вже створений акаунт.

## 1.0.0
Базовий каркас:
- Запит дозволу на повний доступ до сховища (`/sdcard/Download/lgram`).
- Структура папок: `accounts/`, `config/`, `downloads/`, `cache/`, `logs/`.
- Штатний вхід через Telethon: номер телефону → код → (за потреби) 2FA-пароль.
- Підтримка кількох акаунтів одночасно (кожен — окремий `.session` у своїй підпапці).
- Реєстр акаунтів (`config/accounts.json`) + редаговані дефолтні `api_id`/`api_hash`
  (`config/credentials.json`).
- Бічне гамбургер-меню зі списком акаунтів; неактивна сесія показується кольоровим
  кружечком з першою літерою назви замість видалення.
- Фонова перевірка живучості сесії при кожному відкритті застосунку.
